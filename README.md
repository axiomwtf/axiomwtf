# axiomwtf

**Axiom** is a small independent software studio.

We build tools the way they should have been built: one output, no
sidecars, signed by default, and no wrappers around someone else's
config soup.

How we work:

- **Take the obvious route.** If there's a boring way to do something,
  that's the way we do it.
- **Fewer parts.** Every extra piece is something that can break later,
  so we keep cutting until only what's needed is left.
- **Mind the small stuff.** Little details decide whether a tool feels
  right, so we spend time on them.
- **Our own way.** We're independent and opinionated. Nobody signs off
  on our work but us.
- **No sidecars.** Companion files and helper processes count as bugs.
  If something can ship as one file, it ships as one file.
- **Easy to maintain.** We'd rather write code that's still easy to fix
  years from now than code that's fashionable today.
